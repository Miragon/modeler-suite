# Open the source to the side

Click the **Open Source to the Side** button in the editor title of a diagram, or run
[Open Source to the Side](command:__NOTATION__.openSource), to open the `.__EXT__` text beside the
canvas. In the text editor, **Open Diagram to the Side** does the reverse.

Both show the same document: type a line such as `node pack "Pack parcel" [280, 200]` and the node
appears on the canvas; move it on the canvas and its coordinates change in the text. Undo works on
the document, from either side.
