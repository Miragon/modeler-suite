# Create a diagram

Click [Create empty diagram](command:__NOTATION__.newDiagram), pick a name and a folder, and the
new `.__EXT__` file opens as a diagram. You can also run **__DISPLAY_NAME__: New Empty Diagram**
from the Command Palette (`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux), or choose
**File › New File… › __DISPLAY_NAME__ Diagram**.

The file is plain text and stays the source of truth: save, Git, diff and undo all work on it.
Pick a tool from the palette to start; the hint in the middle of an empty diagram offers
**Insert example** as well.
