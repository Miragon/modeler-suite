# Open the example

Click [Create diagram from example](command:__NOTATION__.newDiagramFromExample) to save the
example as a new file. It is an order fulfilment in four steps: place the order, take the payment,
pick the items and ship the parcel.

You can also run **__DISPLAY_NAME__: New Diagram from Example** from the Command Palette, or
choose **File › New File… › New __DISPLAY_NAME__ Diagram from Example**.
