# __DISPLAY_NAME__ Modeler for VS Code

View and edit __DISPLAY_NAME__ diagrams as a canvas, backed by plain-text `.__EXT__` files: the
file stays the source of truth, so dirty state, saving, Git, diff and undo work as for any text
file. Open the source to the side and both stay in sync.

The walkthrough **Get Started with the __DISPLAY_NAME__ Modeler** is the first stop: it creates a
diagram, opens the example and puts the source beside the canvas.

- **__DISPLAY_NAME__: New Empty Diagram**: pick a location for a new `.__EXT__` file (also under
  **File › New File…** as **__DISPLAY_NAME__ Diagram**).
- **__DISPLAY_NAME__: New Diagram from Example**: the same, pre-filled with the example (also under
  **File › New File…** as **New __DISPLAY_NAME__ Diagram from Example**).
- **__DISPLAY_NAME__: Open Source to the Side**: the text beside the diagram, also a button in the
  diagram's editor title; **Open Diagram to the Side** in the text editor's title does the reverse.
