# Value Chain

ARIS-style value-added chain diagrams: steps as chevrons, organizational units as ellipses, predecessor and hierarchy relations.

![The Value Chain web app editing its example](/shots/value-chain/demo.gif)

## File formats

`.vc` and `.vc.json`.

## Use it

- **From source:** `npm run value-chain dev:webapp` opens the editor at `http://localhost:5181`.
- **Library:** `@miragon/value-chain-renderer`
