# Context Maps

Strategic Domain-Driven Design context maps: bounded contexts coloured by subdomain type, connected by context-mapping patterns.

![The Context Maps web app editing its example](/shots/context-maps/demo.gif)

## File formats

`.cm` and `.cm.json`; imports [Context Mapper](https://contextmapper.org/) `.cml`.

## Use it

- **Web app:** [context-maps.modeler.miragon.io](https://context-maps.modeler.miragon.io)
- **VS Code:** [Context Maps Modeler](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.context-maps-modeler)
- **Library:** `npm install @miragon/context-maps-renderer`
