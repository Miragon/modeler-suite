# Wardley Maps

Create, edit and embed [Wardley Maps](https://learnwardleymapping.com/): components on the value chain and along evolution, evolved by drag.

![The Wardley Maps web app editing its example](/shots/wardley-maps/demo.gif)

## File formats

`.wmap` and `.owm`, the [OWM DSL](https://docs.onlinewardleymaps.com/), lossless in both directions.

## Use it

- **Web app:** [wardley-maps.modeler.miragon.io](https://wardley-maps.modeler.miragon.io)
- **VS Code:** [Wardley Mapping Modeler](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.wardley-mapping-modeler)
- **Orca:** [Open in Orca](https://onorca.dev/plugins/miragon.wardley-maps-modeler?catalog=https://github.com/miragon/orca-modelers.git), the plugin from Miragon's [catalog for Orca](https://github.com/Miragon/orca-modelers) ([what it does in Orca](https://github.com/Miragon/modeler-suite/tree/main/modelers/wardley-maps/apps/orca#readme))
- **Library:** `npm install @miragon/wardley-renderer`
