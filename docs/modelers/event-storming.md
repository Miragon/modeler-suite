# Event Storming

Digital [Event Storming](https://www.eventstorming.com/) boards for big picture, process and design level: stickies on a timeline, no grid.

![The Event Storming web app editing its example](/shots/event-storming/demo.gif)

## File formats

`.storm`, a line-based text format with one sticky, note or arrow per line.

## Use it

- **Web app:** [event-storming.modeler.miragon.io](https://event-storming.modeler.miragon.io)
- **VS Code:** [Event Storming Modeler](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.event-storming-modeler)
- **Library:** `npm install @miragon/event-storming-renderer`
