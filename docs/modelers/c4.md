# C4 model

The [C4 model](https://c4model.com) of a software system as one Structurizr DSL workspace: one model, many views, from the system landscape down to the components, drawn and laid out on a canvas.

![The C4 Modeler web app with the system landscape of its example](/shots/c4/editor.png)

## File formats

`.c4`, the modeler's own file, and `.dsl`, such as `workspace.dsl`: both hold a Structurizr DSL workspace. Structurizr's own tools look for the `.dsl` name, so the web app exports the same bytes either way. The modeler reads and writes the file losslessly: an edit on the canvas changes only the lines it touches, and the layout of each view goes into that view's `properties`, so the file still opens in Structurizr. A new workspace starts with the classic C4 colours as tag styles. The canvas edits system landscape, system context, container and component views; deployment, dynamic, filtered, custom and image views, `!docs`, `!adrs` and scripts stay in the file exactly as written.

Compatible with Structurizr DSL. Structurizr is a product of Structurizr Limited; this project is not affiliated with or endorsed by Structurizr Limited.

## Use it

- **From source:** `npm run c4 dev:webapp:plain` opens the editor at `http://127.0.0.1:5182`, `npm run c4 dev:webapp` through Portless. The web app keeps the workspace and the view it shows in the URL's hash after every change, so a reload or a copied link brings both back.
- **VS Code:** [C4 Modeler](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.c4-modeler). A `.c4` file opens in it; a `.dsl` file opens as text, and in the C4 Modeler through **Open Diagram to the Side** or **Reopen Editor With…**. With LikeC4 installed, which uses `.c4` too, a LikeC4 model opens as text.
- **Library:** `npm install @miragon/c4-renderer`
