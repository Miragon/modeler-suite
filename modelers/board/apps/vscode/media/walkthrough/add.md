# Add a model from the picker

**Model** in the board's toolbar lists the models of your repository: Wardley Maps, Event
Storming boards, Team Topologies, Context Maps, Value Chains, C4 models and Business Model
Canvases. Pick one and it is a node on the board, drawn by the editor of its notation.

The board stores where the file sits and never what is in it. Rename or move the file in VS Code
and the node follows; the board then has an unsaved change.

A file no notation of the board covers is a card with its name. **Open in its editor** on the
card opens the file as VS Code opens it.

**Text**, **Image** and **Group** add notes, pictures and groups around the models, and arrows
connect them.
