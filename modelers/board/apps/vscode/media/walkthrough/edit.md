# Edit it in place

Double-click a model node, or press **Edit** in its header, to edit the model where it sits. The
board moves to the node at 100 %, and the notation's own editor takes the mouse and the keys.
**Done**, or a zoom of the board, ends the editing.

What you change is written into the model's own file as the smallest edit, and the file shows
as unsaved. A text editor or the model's own editor beside the board works on the same text:
type there and the node follows.

Cmd/Ctrl+Z inside a model you are editing undoes in that model. On the board it undoes the
board's last change.
