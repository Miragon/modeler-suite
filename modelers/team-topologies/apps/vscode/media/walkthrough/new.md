# Create a diagram

Team Topologies diagrams live in `.tt` files (or `.ttm.json`): plain JSON that opens in a visual
editor instead of as raw text.

**Do this now:** click **Create empty diagram** in the step on the left. (You can also open the
Command Palette with `Cmd/Ctrl+Shift+P` and run **Team Topologies: New Empty Diagram**, or choose
**File › New File… › Team Topologies**.)

1. A save dialog appears: choose a folder and a file name ending in `.tt` and confirm.
2. The file opens in the visual editor. An empty diagram shows "Pick a tool from the palette to
   start." and an **Insert example** button.

Drag a team type from the palette onto the canvas, or press Enter on it to place a team in the
middle. Any file ending in `.tt` or `.ttm.json` opens in this editor automatically from now on.
