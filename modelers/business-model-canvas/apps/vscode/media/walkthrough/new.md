# Create a canvas

**Business Model Canvas: New Empty Business Model Canvas** asks where to save the file and opens it
in the canvas editor. The file is plain text (`*.bmc`), so it diffs, merges and reviews like any
other text file, and an agent can write it. You can also choose it in the New File menu:
**File › New File… › Business Model Canvas**.

An empty canvas shows all nine blocks, and each empty block asks its question in a hint.
