# Open the source to the side

Click the **Open Source to the Side** button in the editor title of a canvas, or run
[Open Source to the Side](command:c4.openSource), to open the Structurizr DSL text beside it. In the text
editor, **Open Diagram to the Side** does the reverse.

Both show the same document: add a line such as `admin = person "Administrator"` inside `model` and
the person appears in the views that include everyone; rename an element on the canvas and only its
name changes in the text. Undo works on the document, from either side. Comments, formatting and
everything the canvas doesn't show stay as you wrote them.
