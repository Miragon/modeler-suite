# Open the example

Click [Create diagram from example](command:c4.newDiagramFromExample) to save the example as a
new file. It is an online bookshop: a customer, the shop's web app, API and database, a payment
provider and an e-mail system, with a landscape, a context, a container and a component view.

The example also holds a dynamic view and a deployment environment. The C4 Modeler keeps them in
the file as they are and lists them under **Views…**; Structurizr shows them.

You can also run **C4: New C4 Diagram from Example** from the Command Palette, or choose
**File › New File… › New C4 Diagram from Example**.
