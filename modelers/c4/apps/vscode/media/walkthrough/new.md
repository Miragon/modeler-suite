# Create a diagram

Click [Create empty diagram](command:c4.newDiagram), pick a name and a folder, and the new
`workspace.c4` opens as a canvas. You can also run **C4: New Empty C4 Diagram** from the Command
Palette (`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux), or choose
**File › New File… › C4 Diagram**.

The file is plain Structurizr DSL and stays the source of truth: save, Git, diff and undo all work
on it, and the Structurizr tools still open it (Structurizr local reads `workspace.dsl` by default,
so give the file that name for it). Pick a tool from the palette to start; the hint in the middle
of an empty diagram offers **Insert example** as well.
