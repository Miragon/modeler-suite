# Create a map

Click [Create empty map](command:wardley.newMap), pick a name and a folder, and the new `.wmap`
file opens as a map. You can also run **Wardley: New Empty Map** from the Command Palette
(`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux), or choose
**File › New File… › Wardley Map**.

The file is plain text and stays the source of truth: save it as `.wmap` or `.owm`, and Git, save
and diff all keep working. Pick a tool from the palette at the top to start; the hint in the
middle of an empty map offers **Insert example** as well.
