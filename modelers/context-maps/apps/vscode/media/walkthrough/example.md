# Open the example

The example is a context map of a conference event planner (after Kaiser's "Architecture for
Flow"): all three subdomain types and four relationship patterns, with their integration roles.

**Do this now:** click **Create diagram from example** in the step on the left. (You can also run
**Context Maps: New Diagram from Example** from the Command Palette, or choose
**File › New File… › New Context Maps Diagram from Example**.)

Choose where to save it; the map opens in the visual editor. Move the contexts around, select one
for its context pad, or open the **Legend** from the menu at the top left.

Already have a Context Mapper model? **Context Maps: New Diagram from CML…** turns a `.cml` file
into a new `.cm` file.
